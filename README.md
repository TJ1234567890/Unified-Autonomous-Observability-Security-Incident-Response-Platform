# Unified-Autonomous-Observability-Security-Incident-Response-Platform
Unified Kubernetes platform for autonomous observability, security, and search. Integrates eBPF, Kafka, and Beam for real-time telemetry with ML models for latency/leak prediction. Features a secure GenAI gateway and a RAG-based "Incident Copilot" to automate triage, summaries, and runbook ranking.

## Prerequisites
- Python 3.9+
- Docker (for local Elasticsearch)
- Confluent CLI (brew install confluentinc/tap/cli)
